Backend Ready

This PWA uses a clean data model and a sync layer. By default it stores data locally. To connect a backend, set API_BASE in the script and implement the listed REST routes.

GET/families/current

Load parent, children, wallets, goals, achievements.

POST/families/current/sync

Save full local state after edits.

POST/children

Create child profile.

POST/contributions

Create payment intent / contribution record.
